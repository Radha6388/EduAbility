# EduAbility 🤖

EduAbility is an AI-based assistant designed for children with learning disabilities.  
It helps them learn through voice interaction, simple UI, and guided activities.

## 🚀 Features
- AI Voice Assistant
- Interactive UI for kids
- Speech-based learning
- Daily life skill modules

## 🛠 Tech Stack
- Java (Android)
- XML (UI)
- AI Integration (Basic)

## 📱 How to Run
1. Clone the repo
2. Open in Android Studio
3. Run on emulator or device

## 🎯 Goal
To make learning simple, interactive, and accessible for children.
